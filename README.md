# DiffCorr (Python)

A Python port of the R package [**DiffCorr**](https://github.com/afukushima/DiffCorr) —
analyzing and visualizing **differential correlation networks** in biological data.

DiffCorr identifies pattern changes between two experimental conditions in
correlation networks (e.g. gene co-expression or metabolite networks). It builds
on Pearson's correlation and tests differential correlation between conditions
with Fisher's Z-test and a local false discovery rate (a faithful port of the
`fdrtool` lFDR estimator).

## Installation

```bash
pip install diffcorr            # core
pip install "diffcorr[plot]"    # with matplotlib plotting helpers
```

From this repository:

```bash
pip install ./python
```

## Data convention

Tables are **rows = molecules** (genes/metabolites), **columns = samples** —
the same orientation as the R package. Inputs may be `pandas.DataFrame`
(molecule labels taken from the index) or `numpy.ndarray`.

## Quick start

```python
import numpy as np
import diffcorr as dc
from diffcorr import datasets

leaves = datasets.load_AraMetLeaves()          # 59 metabolites x 50 samples
cond1 = np.log10(leaves.iloc[:, 0:17])         # Col-0
cond2 = np.log10(leaves.iloc[:, 17:37])        # tt4

# Differential correlation between the two conditions
res = dc.comp_2_cc_fdr(cond1, cond2, method="pearson", threshold=0.05)
print(res.head())

# Hierarchical clustering of molecules + module extraction
hc = dc.cluster_molecule(cond1, method="pearson", linkage_method="average")
groups = dc.cutree(hc, h=0.4)
modules = dc.get_eigen_molecule(cond1, groups)
g = dc.get_eigen_molecule_graph(modules)       # networkx.Graph
```

## Fidelity to the R package

Numeric outputs are validated against the R implementation (see
`tests/`, which compare against reference values generated by R DiffCorr +
`fdrtool` + `pcaMethods`): `get_lfdr` matches `fdrtool` to ~1e-12, and
`comp_2_cc_fdr`, scaling, distances, clustering heights, `cutree` group
assignments, eigen-molecule sizes/mean correlations, and module-graph edge
counts all match.

Two intentional differences from the R code:

- **`uncent_cordist`** returns the intended *square* `n x n` distance matrix.
  The R version allocated a non-square `nrow x ncol` matrix (a latent bug that
  left most columns at zero); the populated entries are identical.
- **`cluster_molecule(..., linkage_method="ward")`** uses SciPy's `ward`
  (Ward.D2). R's `"ward"` is Ward.D, which has no exact SciPy equivalent; a
  warning is emitted. Other linkages (`average`, `complete`, `single`,
  `mcquitty`→`weighted`, `median`, `centroid`) match.
